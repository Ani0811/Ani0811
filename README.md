## 👨‍💻 About Me

I'm a software developer who enjoys building **practical, complete software systems** across web, desktop, mobile, and AI.

My development journey started with full-stack web applications and gradually expanded into backend engineering, desktop software, Android development, machine learning, and AI-assisted development.

I enjoy working across the entire development lifecycle — from **planning and system design to implementation, debugging, deployment, and refinement**.

I'm particularly interested in understanding how different parts of a system work together and building software that goes beyond a simple demonstration to become something genuinely useful.
